# 对白修订：潜台词、双重功能与去直白 (Dialogue Revision — Screenwriter Layer)

本文件是 JMCAI Shotlist Builder 的**编剧层**：它负责把"台词写对、写狠、藏得住"，与只负责"怎么说"的表演层（`MINIMAX_H3_ACTOR_DIALOGUE_CRAFT.md`、`MINIMAX_H3_EMOTION_PERFORMANCE.md`、`MICRO_BEATS.md`）分工明确。

> **授权边界（硬性）**：默认**逐字保留**剧本原文（见 `SKILL.md` Hard invariants）。本文件仅在用户**明确授权**"帮你改台词 / 润色 / 重写 / 原创对白"时启用。启用后：
> - 只改"怎么说"，**不改"发生了什么"**——不得新增或删除剧情事实、人物、动机、信息、道具状态；
> - 改动必须先给**改动清单（diff）**并取得用户确认，再进入提示词；
> - 未获授权时，只能对原文做**标注式建议**（写出问题与备选，不替换原文）。

## 0. 启用与授权分级

| 用户意图 | 允许的动作 |
| --- | --- |
| 未提及改台词 | 逐字保留；发现问题仅在旁注中标"对白风险"，不改原文 |
| "润色 / 更口语 / 更狠一点" | 在**不改事实**前提下改措辞、节奏、语气；列出 diff |
| "重写这段对白 / 我只要意思" | 可重构句式与信息顺序，但保留原意与事实；冲突信息先问 |
| "原创 / 帮我写对白" | 按人物声线（`VOICE_BIBLE`）与类型包新写；仍须符合剧情事实 |

## 1. 对白四问（诊断）

对每一句拟修改的台词，先回答四问；答不上就不要改：

1. **潜台词**：人物真正想要的是什么？他/她说出来的和想要的是同一件事吗？（同级 = on-the-nose，需藏）
2. **双重功能**：这句除了"给信息"，是否还**暴露人物**（性格/处境/关系变化）？只有单一功能的台词通常可删或可并。
3. **可省性**：删掉它，观众是否仍能看懂？（能删就删，或改成动作/画面）
4. **不可替代性**：这句是否只能由**这个人、在这个时刻**说出？换个人说、换个时点说都成立的，往往是废句。

## 2. 六种常见病与改法

| 病 | 症状 | 改法 |
| --- | --- | --- |
| 直白（on-the-nose） | 把情绪/意图直接说破："我现在很生气，因为你骗了我。" | 把真意藏进**反驳、行为、物件、沉默**——"茶凉了。"（潜台词：我已经知道了） |
| 解释性台词 | 人物互相解释观众已知的事，为交代而交代 | 前置为动作/画面证据；台词只说**新信息** |
| 汇报式（as you know） | "如你所知，我们是同父异母的兄弟。" | 让关系在冲突中**被撞出来**，不靠人物自述 |
| 同义重复 | 三句话说的是同一件事 | 合并成一句；多出的留给反应镜头 |
| 说教/总结 | 结尾人物总结主题 | 用**最后动作或稳定画面**收（呼应 `afterimage`），不说破 |
| 腔调失真 | 全员一个腔（播音腔/霸总腔） | 按 `VOICE_BIBLE` 的多角色差异重写咬字与句尾；校验"禁忌读法" |

## 3. 潜台词技术（把真意藏起来）

- **顾左右而言他**：问 A 答 B，B 泄露真实态度。
- **以行动/物件代言**：不说不满，只是把东西推远、拂去灰、慢条斯理地擦。
- **把真意藏进反驳**：否认得越具体，暴露得越多。
- **答非所问 / 反问**：用问题夺回主动权。
- **沉默与停顿**：该说不说——把空间留给对手与观众。
- **降级陈述**：用极平淡的语气说极重的事（反差即杀伤力）。

> 原则：**信息可以直给，情绪必须包裹。** 观众要"看见"情绪，而不是"被通知"情绪。

## 4. 双重功能检验

每句台词应至少完成两项中的一项（理想是两项都有）：

- **推进**：改变情节、关系或信息状态（新的认知/决定/威胁）；
- **暴露**：暴露说话者的性格、处境、欲望，或他与听者的关系变化。

只有一项且可有可无的台词，按 §2 合并或改为动作。

## 5. 信息节流与揭示节奏

- **延迟揭示**：关键信息不在首次可给时给——这是打脸、揭穿、反转的发动机（与 `SHORT_DRAMA_STRUCTURE.md` §5 呼应）。
- **谁先知道**：制造"观众比角色先知道"（悬念）或"角色比观众先知道"（反转）的信息差，让台词承担**说还是不说**的选择。
- **一次只给一块**：一句台词不要把整段背景倒完；拆给后续行动与反应镜头。

## 6. 保留原文的边界（哪些绝不能改）

- 剧本正文与用户当前修正＝内容真值；**事实、因果、人物关系、姓名、专有名词不得动**。
- 台词一旦被确认为"逐字保留"，标点与语气词也逐字保留（`MINIMAX_H3_LONG_SCRIPT_UNITS.md` §2）。
- 情绪可以改，信息不可以改；措辞可以改，事实不可以改。

## 7. 与表演层 / 时序层的衔接

- 改后的台词交 `MINIMAX_H3_ACTOR_DIALOGUE_CRAFT.md` / `MICRO_BEATS.md` 做**可演化**（意图、重音、呼吸、句尾）；
- 字数变化必须重算时长与字数预算（数值真源：`MINIMAX_H3_TIMING_ENGINEERING.md`）；
- 中英双稿必须同步（`MINIMAX_H3_DUAL_PROMPT_CONTRACT.md`），改动一处视为未完成，直到两侧一致。

事实是否有变化必须明确标注；有变化的必须先经用户确认。
