# 情绪过程导演 (Performance Process Direction)

> **第一原则：情绪是一段「过程」，不是一个形容词。**
> 禁止把「开心地笑 / 悲伤 / 温柔 / 愤怒」这类结论直接写进提示词。必须先**发生**、再**维持**、再**泄露**、再**完成**：只写观众能看见或听见的变化，让人物在有限时长内自然进入、维持、泄露并完成情绪。

本文件是 jmcai 的**表演总纲（跨 Seedance / MiniMax H3）**，负责把"发生了什么情绪"翻译成"看得见的变化过程"。它**不改变**剧本真值、台词、路由、时序工程与连续性契约；线索素材见 `MICRO_BEATS.md`，H3 执行卡见 `MINIMAX_H3_MICRO_EXPRESSION.md` 与 `MINIMAX_H3_EMOTION_PERFORMANCE.md`。与平台契约或数值真源冲突时，**平台契约与数值真源优先**。

## 0. 何时启用

- 任何含人物情绪、表情、倾听反应或长镜头表演的镜头；
- 六类任务：单一表情 / 渐变情绪 / 转折情绪 / 混合情绪 / 台词表演 / 双轨长镜头（外部任务 + 内部失守）；
- H3：在 `MICRO_PERFORMANCE_SCORE` 与 `EMOTIONAL_RHYTHM_MAP` 之前，先过本文件；
- Seedance：在写人物神态与反应之前，先过本文件。

## 1. 表演强度刻度（1–10）

| 档位 | 含义 |
| :--- | :--- |
| 1–3 | 克制 |
| **4–6** | **自然（默认）** |
| 7–8 | 强烈 |
| 9–10 | 爆发 |

- 默认 **4–6**：优先"微弱、轻微、几乎看不见、克制"，避免默认满格表演。
- 只有用户/剧情明确要求爆发才升到 **7+**，且仍须保留发生过程与自然回落。
- 整段不得锁死在同一强度；必须有出现—维持—回落。

## 2. 表演设计六步（不得跳过过渡逻辑）

1. 建立初始状态与强度；
2. 设置可理解的触发点（台词 / 动作 / 事件 / 回忆涌现 / 一次呼吸停顿）；
3. 短暂维持、掩饰或抵抗；
4. 用 **1–2 个微表情**泄露真实情绪；
5. 让 A 与 B **短暂桥接并存**；
6. 目标情绪完成转折并停留片刻。

## 3. 双轨：外部任务线 + 内部情绪线

- **先锁外部任务不变量**：人物正在持续做什么，哪些姿势 / 方向 / 道具 / 空间关系不得改变，什么条件下任务才被解除。
- **除非剧本或用户明确要求，不因害怕、悲伤或流泪就擅自让人物放下道具、停车、转身、低头、后退、捂脸或停止任务。** 冲突写在眼神、呼吸、嘴部与面部肌肉里。
- 同时定义**三层**：
  - **公开层**：为职责、尊严、谎言或保护他人而维持的表情；
  - **隐藏层**：正在积聚、试图泄露的真实情绪；
  - **残留层**：前一阶段没有消失、仍留在脸上的情绪痕迹。
- 反例："惊恐消失，变成伤心。" 正例："警觉没有完全消失，惊恐从眼神里渗入；随后悲痛覆盖上来，嘴角与下巴开始失守，但目光里仍残留不敢相信。"

## 4. 波浪式失守（含「压回」节拍）

```text
维持控制 → 出现裂缝 → 短暂压回 → 情绪反弹 → 再次控制失败 → 最终失守
```

- **「压回」是必需要拍点**：嘴唇重新抿住 / 呼吸暂时恢复 / 闭眼后重新睁开 / 下颌重新绷紧 / 视线重新锁定 / 表情幅度短暂减小。
- 反弹只升级 **1–2 个通道**（水光→泪滴、无声换气→破碎呼吸、嘴唇轻启→想说话却发不出声、下巴绷紧→克制颤抖）。
- **禁止**所有面部与身体通道同时满格；**禁止**情绪直线上升（会显得机械）。
- 长镜头至少要有**一次**"压回或恢复控制"。

### 写作模板（双轨长镜头）

```text
[时长与镜头]。外部任务始终保持：[不可改变的动作、道具、方向和站位]。

[阶段一] 人物公开维持[表层状态]，但[隐藏情绪]已经通过[极弱线索]泄露。

[阶段二] 因为[触发或认出]，[眼神或呼吸]先出现裂缝；[旧情绪]没有消失，[新情绪]开始渗入。人物的视线短暂[闭眼/失焦/侧移]，随后重新回到[关系锚点]。

[阶段三] 人物试图恢复控制：[压回动作]，表情幅度短暂减小；外部任务仍保持不变。

[阶段四] 情绪再次反弹，[泪水/声音/嘴角/下巴]升级；人物出现[未完成表达]，但不增加台词。

[最终阶段] [复合情绪]同时停留在脸上。除非剧情明确要求，人物不自动停止外部任务。
```

### 参考范例（举枪认出战友）

外部任务始终保持：举枪姿势、枪口方向和站位不自动改变。

1. 公开层保持警觉，眼眶与嘴唇先泄露不敢相信；
2. 视线短暂侧移或失焦，再回到战友脸上确认；
3. 嘴唇轻启，像要叫出名字，但没有声音；
4. 重新抿住嘴唇并控制呼吸，短暂收回表情；
5. 情绪再次反弹，眼泪出现，下巴与嘴角开始克制颤抖；
6. 最终哭意明显，但职责、自责与不敢相信仍同时存在；外部动作是否解除取决于剧情，不由情绪自动决定。

## 5. 关系视线锚点

- 先确定锚点（对方 / 孩子 / 敌人 / 画外声音 / 关键物品），再判断人物能否移开视线。
- 职责或对峙：多数时间锁定对方，允许短暂失焦 / 闭眼 / 侧移后**重新锁定**；羞耻或逃避允许较长时间避开，但要写清原因；告别可反复离开又返回；震惊认出先停住或失焦，再重新确认。
- **禁止**为"自然"让视线随机游移。H3 的 `SPATIAL_BLOCKING.md` 轴线与视线规则仍优先。

## 6. 减法式微表达（三层法）

```text
强度控制 + 动作归因 + 时间顺序
```

- **强度控制**：使用低强度程度词（微弱 / 轻微 / 几乎看不见 / 克制 / 抓拍非摆拍），每段取 1–2 个，不机械堆砌。
- **动作归因**：先写人物"因为什么"而低头、移开视线、闭眼、换气或松肩，再写表情浮现——让表情成为身体、视线、呼吸的结果，而不是直接摆表情。
- **时间顺序**：至少 `起始状态 → 触发与变化 → 最终微表情`；复杂转折走完整情绪弧线。
- 只选与情绪有因果关系的 **1–3 个**物理动作；不为"生活感"机械加咬唇、挽发、挠头、揉眼。

### 对照改写（弱写法 → 减法写法）

| 情绪 | 弱写法（结论） | 减法写法（过程） |
| :--- | :--- | :--- |
| 开心 | 女人喝着咖啡，开心地笑着，享受这个早晨。 | 她轻轻举起杯子闻到咖啡香气，双眼自然闭合一瞬，随后缓慢吹散杯口的热气，暂时没有喝下。面部肌肉逐渐放松，嘴角浮现很淡的舒适笑意，呼吸平稳，没有看向镜头摆姿势。 |
| 害羞 | 她害羞地一直看着镜头，对观众微笑。 | 听见对方的话后她立刻垂下视线，轻轻收住下巴，不敢继续对视；目光紧张地向旁边瞥了一下，嘴唇轻轻抿住，随后才出现一个克制而短暂的害羞笑意。 |
| 释然 | 男人露出释然的笑容。 | 开始时他神情严肃而克制，望着远处。随后缓慢闭上双眼，完成一次清晰而平稳的深呼吸，肩膀随呼气轻轻下沉。重新睁眼时目光已柔和下来，嘴角才慢慢浮现一个很淡的释然笑容。 |

> 共同因果链：先有刺激或身体动作 → 视线 / 呼吸改变 → 身体放松 → 低强度表情最后浮现。

## 7. 未完成表达（无台词时）

只呈现"想说而没说出"的状态：

- 嘴唇像要叫出名字般轻启，最终没有声音；
- 吸气准备说话，却在第一个音节前停住；
- 嘴唇张开又重新抿紧；
- 喉咙吞咽，呼吸从鼻腔转成破碎的口呼吸；
- 声音被哭腔堵住，只留下极轻的气声。

**禁止擅自补出用户没有提供的台词。**

## 8. 情绪歧义三分（先判逻辑，再动笔）

- **喜极而泣**（正向情绪溢出，笑意与泪水同源）；
- **悲伤穿透笑容**（笑意仍在，悲伤从眼底渗入）；
- **伪装的笑崩溃**（公开层笑意先撑住，随后失守）。

上下文不足且不同解释会显著改变表演结果时，用**一个**简短问题确认；否则选择最合理解释，在提示词里自然落实，不额外解释。

## 9. 台词与表演绑定时点

- 台词**原样保留、不擅自续写**；标明开始说话的时点与对象、音量 / 语速 / 语气 / 重音 / 停顿、**哪个字句触发表情变化**、说完后的呼吸 / 视线 / 余韵、口型与情绪同步。
- 台词超载：先指出冲突，再给最小改动方案，**不偷偷删词**（数值真源见 `MINIMAX_H3_TIMING_ENGINEERING.md`）。多人台词标清说话者与轮次。

## 10. 表演失败模式 → 改法

| 失败现象 | 改法 |
| :--- | :--- |
| 突然变脸 | 延长触发与桥接阶段，降低最终情绪强度 |
| 表情冻结 | 加入一次自然眨眼 / 换气 / 视线变化 / 笑意回落 |
| 表演夸张 | 强度降到 3–5，删除大幅肢体动作与"崩溃 / 嚎啕"等词 |
| 只哭不笑 / 只笑不泪 | 补写另一侧的因果过程（笑意在泪水出现后仍保留微弱；眼眶积聚水光 → 一滴自然滑落） |
| 口型与情绪脱节 | 把变化绑定到具体关键词、停顿与台词结束后的余韵 |
| 人物崩脸 | 稳定近景 / 单镜头 / 小幅动作，限制五官、身份与发型变化 |
| 情绪一来就停任务 | 锁外部任务为不变量，只允许必要的肌肉、呼吸与视线变化 |
| 情绪直线上升机械 | 中段加入一次短暂恢复控制，再以更高强度反弹 |
| 无故移开视线 | 明确关系视线锚点，只允许短暂偏移后回到锚点 |

本表用于**提示词层**预防；成片级修复流程仍走 `VIDEO_CONTINUITY_FIXES_CHECKLIST.md`。

## 11. Seedance 情绪时间表达

- **情绪推进层**：优先语义 / 因果节拍（`开场 → 随后 → 中段 → 短暂压回 → 后半段 → 结尾`），**不把微表情钉到小数秒**。
- **分镜 / 多镜层**：仍按 Seedance 2.5 官方 `[0-5s]` **秒级锚定**与 `SEEDANCE_25_PRODUCTION_SPEC.md`、`PROMPT_DENSITY.md` 的时长预算使用时间戳。
- **单镜头情绪专拍**（无多镜需求）：总时长只在开头提一次，并提醒用户在生成设置中选择相同总时长；精确时间码只在用户明确要求分镜 / 剪辑表时给出，并标注为"规划用，不保证逐帧执行"。
- **MiniMax H3 例外**：H3 的精确时间窗（`【镜头N｜x.x—y.y秒】`）是硬契约，**不得**改用纯语义节拍；本节的"不写小数秒"**只作用于情绪描述**，不作用于 H3 镜头时间轴。

## 13. 自检

- [ ] 是否写清了初始情绪、触发点、桥接状态与最终情绪？
- [ ] 长镜头是否有一次"压回 / 恢复控制"，而非直线上升？
- [ ] 新情绪是否保留旧情绪痕迹，而不是换成另一张表情面具？
- [ ] 是否锁定外部任务不变量，未因情绪擅自改剧情动作？
- [ ] 视线是否有锚点，短暂偏移后是否回到锚点？
- [ ] 强度是否受控，且整段不是同一张满格表情？
- [ ] 无台词时是否只写未完成表达，没有擅自补台词？
- [ ] 歧义情绪（喜极而泣 / 悲伤穿透笑容 / 伪装的笑崩溃）是否判对？
- [ ] Seedance 是否用语义节拍描述情绪；H3 是否保留精确时间窗？
- [ ] 是否没有添加多余剧情、台词、动作、字幕或切镜？
