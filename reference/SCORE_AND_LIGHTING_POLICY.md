# 配乐策略与类型化摄影档 (Score Policy & Genre Light Packs)

本文件决定**"气势层"的两个默认**：非剧情配乐（`SCORE_POLICY`）与类型化灯光审美（`LIGHT_PACK`）。它不改变剧本真值、台词、H3 路由、时长时序与连续性契约。

> - **MiniMax H3 的摄影**仍严格受 `MINIMAX_H3_DIRECTORIAL_NATURAL_LANGUAGE.md` §零 约束：不得自动注入摄影师姓名、`8K IMAX`、固定调色、固定焦段、固定阴影侧构图；光线必须来自本场真实、可解释的光源。
> - **Seedance 的摄影**仍以 `STYLE_BLOCK.md` 为默认（该块带有 "MiniMax H3 exclusions" 例外说明）。
> - 本文件只在"用户未另行指定"时提供**候选默认**；用户明确指令最高优先。

## 1. 配乐策略档（`SCORE_POLICY`）

短剧的**默认不是"禁音乐"**。默认按题材选档；无用户授权不得擅自加入配乐，但也不得把"写实无配乐"当万能默认。

| 档位 | 触发 | 写法要求 | 中文 `音乐：` 示例 |
| --- | --- | --- | --- |
| `none` | 用户明确禁配乐；或本场追求纯环境真实 | 全片/范围锁定无配乐 | `无配乐。`（英文 `non_diegetic_music: N/A`） |
| `diegetic` | 人物能听见的现场音乐 | 归入对应镜头时间线，**不**进 `非剧情音乐` | 写在 `镜头设计`/`声音` 内 |
| `emotional_canned` | 常规情绪段（加压、暗流） | 写清 **texture / pulse / entry / exit** | `音乐：低频弦乐持续音，约第 4 秒随门响进入，第 11 秒切断。` |
| `theme_motif` | 主角/核心关系的主题动机 | 同一动机跨单元/跨集复用，写清配器与变形 | `音乐：苏晚主题（单簧管），弱奏进入，结尾上行未解决。` |
| `stinger` | 反转 / 钩子 / 卡点的一次性重音 | 极短、单次、与画面切点对齐 | `音乐：卡点 stinger，约第 14.5 秒一记低音重击后静默。` |

规则：

- 严禁用**情绪标签**代替配乐设计（"悲伤的音乐""紧张的音乐"→ 必须落到配器、织体、脉动、进出点）。
- 用户禁配乐时，锁定 `none`，全范围一致，不得留下任何配乐提示。
- 现场可听音乐是 `diegetic`，永远写入镜头时间线，不能塞进 `非剧情音乐`。
- `theme_motif` 一旦确立，跨集复用；不得每集换一个主题。

## 2. 卡点与反转的听觉设计

- **反转前**：先**减法**——撤掉配乐或压低织体，让环境声裸露（与 `MICRO_BEATS.md` 的"留白"同源），反转落点更有冲击。
- **反转/打脸落点**：一次 `stinger` 或主题动机的强奏进入，与硬切对齐；不要全程铺满。
- **卡点（cliffhanger）**：常用"未解决终止"——动机上行、悬停、突然静默，与稳定尾态画面配合（见 `SHORT_DRAMA_STRUCTURE.md` §4）。
- 全片配乐要有**呼吸**：不要每个单元都满配乐；密集使用会让卡点失效。

## 3. 类型化摄影档（`LIGHT_PACK`）

`CAMERA_LIGHTING_VOCABULARY.md` 是词库；这里是**成档的审美默认**，按类型选择，再叠加 `STYLE_BLOCK.md` 的场景光变体（Seedance）或 H3 的实景光（H3）。

| 档位 | 适用类型 | 光源逻辑 | 对比度 / 色温 | 典型允许 |
| --- | --- | --- | --- | --- |
| **写实文艺**（默认） | 悬疑、情感、现实题材 | 仅实景光源（practicals），阴影侧取景 | 中低对比，色温随场 | 现有 `STYLE_BLOCK` 全部规则 |
| **强反差网感** | 爽文打脸、战神、身份揭穿 | 明确主光 + 大面积负补光，硬光比 | 高对比，冷暖强对撞 | 硬质 key、剪影、轮廓光；仍禁无来源补光 |
| **暖甜柔光** | 甜宠、都市情感 | 大面积柔和窗光 / 暖 practicals | 低对比，暖调高光 | 柔化、轻微 bloom、通透肤色 |
| **冷冽低照** | 悬疑、复仇、权谋 | 单光源 + 负补光压暗环境 | 高低光比，青蓝阴影 | 低调、暗部堆叠、极少高光 |
| **史诗体量** | 战神、大场面、开场 | 自然光/体积感环境光 | 中高对比，冷暖分区 | 逆光、haze、纵深；避免 god rays 滥用 |

落地规则：

- 任何档位都**不为画面美感而虚构光源**；补光只允许来自场内的反光面、屏幕、灯具等可解释来源。
- H3 分支：把档位特征写进 `角色与场景` / `镜头设计` 的实景光描述，**不**注入摄影师名与固定配方。
- Seedance 分支：在 `STYLE_BLOCK.md` 的光变体之上叠加本档的对比度/色温倾向。
- 单一单元内**只用一个主档**；类型转向靠剧情，不靠中途换光派。

## 4. H3 与 Seedance 的落地差异

| 维度 | MiniMax H3 | Seedance 2.0/2.5 |
| --- | --- | --- |
| 摄影默认 | `DIRECTORIAL_NATURAL_LANGUAGE` §零 + 本档 | `STYLE_BLOCK.md` + 本档 |
| 配乐字段 | 中文 `音乐：` / 英文 `non_diegetic_music` | 风格块内配乐/音效说明 |
| 卡点实现 | 稳定尾态画面 + `stinger`/未解决动机 | 硬切 + 括号标记音效 |
| 画幅 | 记录声明画幅，无 `15秒。21:9。` footer | 默认 `21:9` footer，短剧改 `9:16` |

## 5. 自检清单

- [ ] `SCORE_POLICY` 是否已按用户意图锁定并在全范围一致（`none` 时无任何配乐提示）？
- [ ] 配乐是否写到了 texture / pulse / entry / exit，而非情绪标签？
- [ ] 现场可听音乐是否留在镜头时间线（diegetic），未误入 `非剧情音乐`？
- [ ] `theme_motif` 是否跨单元/跨集复用同一动机？
- [ ] 每个单元是否只用一个 `LIGHT_PACK` 主档，且光线全部有场内来源？
- [ ] H3 是否避免了摄影师名 / `8K IMAX` / 固定配方 / 固定阴影侧？
- [ ] 卡点处是否用了"减法 + 定点重音/未解决终止"，而非全程满配乐？
