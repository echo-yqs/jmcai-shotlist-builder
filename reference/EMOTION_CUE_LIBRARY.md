# 情绪线索库 (Emotion Cue Library)

> 本文件是 [EMOTION_PROCESS_DIRECTION.md](EMOTION_PROCESS_DIRECTION.md) 的**线索素材层**：为"情绪过程"提供每种情绪可用的**可见线索**。取 **2–4 条最有辨识度的线索**，结合人物性格、景别与强度改写；**不要整段照抄，也不要同时驱动所有五官**。更细的肌肉级分解见 `MICRO_BEATS.md`；H3 的执行卡见 `MINIMAX_H3_MICRO_EXPRESSION.md`。
>
> 取材纪律：只取**部位动作与视觉结果**；情绪标签、评价性措辞与编号不随取材进入交付文本。线索必须与剧情、人物关系、场景有**因果关系**，不为"生活感"机械堆砌。

## 1. 笑与愉悦

### 温柔的笑
- 嘴角缓慢、轻微上扬，通常保持闭唇或微微启唇
- 双眼柔和，下眼睑出现很轻的收紧
- 视线稳定地落在对方身上，偶尔轻轻垂眼
- 呼吸平稳，头部可有极小幅度的侧倾
- 避免露齿大笑、眉毛高挑和夸张眯眼

### 开心的笑
- 笑意先从眼睛和脸颊出现，再扩展到嘴角
- 脸颊自然抬起，双眼微弯，嘴角上扬幅度中等
- 可伴随一次短促换气、轻笑或肩膀轻微起伏
- 表情出现细小变化和自然回落，不全程锁死在最大强度

### 苦笑或无奈的笑
- 嘴角勉强上扬，幅度较小且略有不对称
- 眼神不参与笑意，短暂躲闪或向下移动
- 呼气比吸气明显，下巴或嘴唇短暂绷紧
- 笑容停留很短，随后回落

## 2. 悲伤与泪水

### 克制悲伤
- 目光变慢、失焦或暂时避开对方
- 内眉轻微抬起或眉间出现很浅的收紧
- 嘴唇抿住、下巴轻轻绷紧，呼吸短暂停顿
- 眼眶逐渐湿润，但不立刻流泪

### 强忍眼泪
- 先眨一次较慢的眼睛，试图把泪水压回去
- 下眼睑轻轻发紧，鼻翼和嘴角出现极小颤动
- 吸气变浅，喉咙像被堵住，说话尾音略微不稳
- 视线可以抬起或移开，但避免连续翻眼和用力挤眼

### 情绪失守
- 在克制阶段后出现一次呼吸断裂或声音卡住
- 嘴角失去控制，下巴出现轻微颤动
- 眼泪先积聚，再有一滴自然滑落
- 强度较高时才加入连续落泪、肩膀抽动或哭声

## 3. 紧张、恐惧与惊讶

### 紧张
- 眨眼频率略有改变，视线短暂游移后重新锁定目标
- 嘴唇抿紧或轻轻张开，吞咽一次
- 呼吸变浅，肩颈略微绷紧
- 眉间轻蹙，不默认睁大双眼

### 恐惧
- 眼睛逐渐睁大，视线固定在威胁来源
- 眉毛抬起并向内收，下唇或呼吸出现颤动
- 身体先僵住，再出现很小的后缩或屏息
- 避免一开始就张大嘴尖叫，除非用户要求爆发强度

### 惊讶
- 眉毛快速抬起，眼睛短暂睁大
- 嘴唇轻启，呼吸停顿半拍
- 之后必须落入第二情绪，如惊喜、警觉、怀疑或恐惧

## 4. 愤怒、失望与决心

### 克制愤怒
- 视线稳定锐利，眉间逐渐收紧
- 下颌绷紧，嘴唇压成较直的线
- 鼻息稍重，但头部和身体保持克制
- 说话音量不必提高，可通过语速变慢和重音表现压力

### 失望
- 原本紧绷的眉间和下颌慢慢松开
- 目光从对方身上移开或缓慢垂下
- 嘴角轻微下沉，呼出一口较长的气
- 愤怒转失望时，让攻击性先消失，再出现疲惫和疏离

### 决心
- 短暂垂眼或吸气后重新抬眼
- 视线稳定、下颌轻收、嘴唇恢复平静
- 表情从摇摆变得清晰，动作幅度减小
- 避免用夸张皱眉代替坚定

## 5. 混合情绪

### 笑中带泪
- 嘴角仍保留笑意，眼神和下眼睑先泄露悲伤
- 笑声逐渐减弱，呼吸停顿，嘴角随后轻轻颤动
- 泪水出现时不要立刻抹去笑容
- 根据剧情区分喜极而泣、重逢后的释然或悲伤穿透笑容

### 哭着笑了
- 先保持湿润眼眶和不稳呼吸
- 某个触发点让视线重新聚焦，嘴角试探性抬起
- 笑意很小，泪痕仍在，呼吸逐渐恢复
- 不要让哭泣痕迹瞬间消失

### 愤怒中的心软
- 眉间和下颌仍紧绷，但视线首先失去攻击性
- 听到触发内容后出现短暂停顿，呼吸放缓
- 嘴唇仍抿紧，眼神却逐渐柔和或避开
- 最终可以保留不情愿、克制和关心同时存在

## 6. 使用纪律与一句话检查

- 每种情绪只取 **2–4 条**最有辨识度的线索，结合人物性格、景别与强度改写。
- **不要整段照抄**，也不要同时驱动所有五官；通道要分级、要有主次。
- 分清"**原因**"与"**结果**"：先写身体、视线、呼吸的原因，再写表情结果（见 `EMOTION_PROCESS_DIRECTION.md` §6）。
- 混合情绪（§5）用于歧义三分（喜极而泣 / 悲伤穿透笑容 / 伪装的笑崩溃）的落地，先判逻辑再取线索。
- 强度由 `EMOTION_PROCESS_DIRECTION.md` §1 的 1–10 刻度决定；只有爆发档才加连续落泪、哭声或大幅肢体动作。

> **一句话检查**：不要只写人物有什么情绪；写清为什么产生、身体先怎么动、眼神如何变化、情绪怎样慢慢出现。

## 7. 常见转折剧本

先确定**转折为何发生**：事件或台词优先；没有触发点时可用回忆涌现、看见某物或一次呼吸停顿，但**不得凭空添加改变剧情的事件**。以下脚本可直接改写；每条只用**一个**主转折，前后动作必须连续。

### 7.1 笑着笑着哭了
1. 真实笑意建立在眼睛、脸颊和嘴角；
2. 笑声或台词在触发词后逐渐减弱；
3. 嘴角继续维持笑意，视线却停顿或失焦；
4. 呼吸卡住，眼眶湿润，嘴角出现细微颤动；
5. 一滴眼泪落下，笑意没有完全消失。

### 7.2 哭着突然笑了
1. 先建立泪水、哽咽或失控后的余波；
2. 触发点让人物愣住，视线重新聚焦；
3. 嘴角先出现不确定的小幅上扬；
4. 笑意扩展但泪痕仍在，形成释然或荒诞感。

### 7.3 愤怒转为失望
1. 眉间、下颌和注视建立克制愤怒；
2. 听见或看见触发内容后停顿；
3. 视线先失去攻击性，下颌和眉间逐渐松开；
4. 目光移开、嘴角下沉、长呼气，落入疲惫与疏离。

### 7.4 强装镇定后失守
1. 表情平静，语速和姿态刻意稳定；
2. 通过吞咽、眨眼或一次浅吸气泄露压力；
3. 关键字处声音卡住，视线避开，嘴唇或下巴轻颤；
4. 眼泪积聚或呼吸断裂，最后才允许情绪释放。

### 7.5 害怕转为坚定
1. 视线游移、浅呼吸和身体轻微僵硬建立恐惧；
2. 人物停顿并完成一次较深吸气；
3. 视线重新锁定目标，下颌轻收，动作幅度减少；
4. 呼吸稳定，眼神明确，恐惧仍有余痕但不再支配人物。

### 7.6 台词绑定示例

台词：「我就知道你一定会回来。」

- 「我就知道」：笑意自然，语气带着确认后的欣喜；
- 「你一定会」：眼神持续落在对方身上，声音开始放慢；
- 「回来」：作为转折词，尾音变轻，笑声停住，呼吸卡顿；
- 台词后：嘴角仍上扬，眼眶逐渐湿润，一滴眼泪落下。

> **时间与节拍**：这些脚本的情绪推进用**语义节拍**（开场 → 随后 → 中段 → 短暂压回 → 后半段 → 结尾），不钉小数秒；精确时间窗与时长分配见 `EMOTION_PROCESS_DIRECTION.md` §11 与 `MINIMAX_H3_TIMING_ENGINEERING.md`。
